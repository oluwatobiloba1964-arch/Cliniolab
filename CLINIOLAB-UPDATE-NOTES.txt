Admin-managed Flutterwave settings are included in the merged payment UI and routes. The encryption key must be a random secret of at least 32 characters; new admin-saved credentials are encrypted with AES-GCM before being stored. Never commit live secrets to source control. Existing legacy admin-saved credentials remain readable for compatibility until they are saved again, at which point they are encrypted.

## Local learning tools update (2026-10)

Added three optional learning features controlled through Admin > Feature flags:
- Learning Tools: Smart Revision Queue (`smart_revision_queue`)
- Learning Tools: Article Study Mode (`article_study_mode`)
- Learning Tools: Topic Knowledge Maps (`topic_knowledge_maps`)

The tools run in the browser. The revision queue reads existing local missed-question records, existing spaced-repetition schedules, and unfinished tasks from the existing local study toolkit. Article Study Mode provides a local summary, recall prompts, saved-for-revision state, and an understood marker. Topic Knowledge Maps use bundled topic relationships and store topic status in the existing local study toolkit record.

No tables or columns are added. Apply `src/db/migrations/2026-10-add-local-learning-feature-flags.sql` once to seed the three rows in the existing `feature_flags` table so the existing Admin > Feature flags controls can manage them. Normal use of the tools adds no database reads, writes, API routes, or Worker/Vercel invocations. The existing public-config request already reads the feature flag map, so the three flags are included in that same read. Changing a sitewide toggle uses the existing admin feature-flag endpoint and updates the existing table.

Account-synced bookmarks are not fetched by the Smart Revision Queue because doing so would require a database-backed request. The queue includes bookmark data only if it is already present in local browser storage. Saved article topics and topic-map progress reuse `cliniolab_local_study_toolkit_v1`, avoiding a separate tracking store. Local progress does not sync across devices and may be lost if browser site data is cleared.
